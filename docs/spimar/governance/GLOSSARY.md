# Glossary

| Term               | Meaning                                                                                         |
| ------------------ | ----------------------------------------------------------------------------------------------- |
| ADR                | Architecture Decision Record                                                                    |
| HIF                | High-fidelity implementation/review target; `HIF-001` through `HIF-048`                         |
| UXF                | UX/wireframe target mapped one-to-one to HIF                                                    |
| POC                | Proof of capability; not production integration or release readiness                            |
| RLS                | PostgreSQL Row Level Security                                                                   |
| SLA                | Operational response or handling target                                                         |
| PII                | Personally identifiable information                                                             |
| RTL                | Right-to-left composition for Arabic, including logical layout behavior                         |
| SPI                | Top-level SPIMAR execution queue phase                                                          |
| TRF                | Bounded Transformation Phase 1 work package nested under an SPI phase                           |
| Gate               | Evidence-backed entry/exit acceptance boundary                                                  |
| Durable submission | A server-validated, idempotent record committed before external provider delivery               |
| Provider status    | CRM/email/calendar/resource outcome after durable storage; never the same as submission success |
| PUBLIC_EDITORIAL   | Immersive public website design-system mode                                                     |
| CMS_EDITORIAL      | Structured review and publishing design-system mode                                             |
| CRM_OPERATIONAL    | Dense lead operations design-system mode                                                        |
