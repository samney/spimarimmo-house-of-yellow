## Coverage rule

A PDF requirement is implementation-ready only when it resolves to:

1. an approved product/route/state/design contract;
2. one canonical Phase 1 Markdown owner;
3. a `TRF-*` work package under the unified delivery map;
4. an evidence-backed gate.

No requirement may exist only in a binary PDF, and no visual choice from the document redesign may silently redefine the website/CMS/CRM design system.
