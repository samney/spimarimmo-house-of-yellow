## Purpose

Phase 08 translates the approved product structure, 48 deterministic `UXF` targets, 144 state proofs, black/gold identity, and Phase 07 component contracts into one governed high-fidelity website system.

This phase defines the finished SPIMAR experience that will later be applied to the repaired and neutralized House of Yellow clone foundation. It does not authorize a clean-slate implementation and does not modify the clone repository.

## What is approved versus still controlled

Approved in this phase:

- the black/gold visual hierarchy;
- the global, event, exhibitor, visitor, proof, resource, editorial, form, legal, and system page grammars;
- CTA priority and outcome language;
- desktop/mobile/RTL transformations;
- missing-media poster treatment;
- lifecycle, sales, registration, provider, and content-state presentation;
- high-fidelity mapping to all 48 `UXF` targets.

Still controlled inputs:

- final vector logo geometry and Arabic lockup;
- licensed production font files;
- rights-cleared event, project, people, and partner media;
- approved claims, metrics, prices, partner marks, testimonials, and results;
- production CMS/CRM/provider decisions;
- moderated user-validation findings;
- repaired clone repository identity and House of Yellow parity acceptance.

## Gate rule

Gate 8 may approve this package as the controlled visual specification while carrying the inputs above. It must not label fixture copy or poster placeholders as final content, and it must not authorize implementation against an unidentified or parity-failing clone commit.
