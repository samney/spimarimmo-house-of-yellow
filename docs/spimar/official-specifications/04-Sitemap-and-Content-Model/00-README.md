## Phase decision

The route system is approved structurally without inventing event names, production hosts, launch dates, venue facts, prices, proof, or locale readiness.

Every event has one canonical public URL family. Exhibitor and visitor journeys use distinct content, actions, forms, and analytics, but they do not create duplicate competing event pages.
