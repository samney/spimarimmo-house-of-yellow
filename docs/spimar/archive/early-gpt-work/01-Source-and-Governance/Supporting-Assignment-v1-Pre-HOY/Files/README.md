## Current product rule

`spimarimmo.com` is the global B2B commercial and credibility platform. Localized
subdomains are event products for country-specific exhibitor conversion and visitor
acquisition.

The primary conversion is an exhibitor sales conversation. Visitor registration is a
secondary conversion and part of the evidence supporting exhibitor ROI.
