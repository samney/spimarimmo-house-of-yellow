## 3. Consistency review

### 3.1 What is coherent

- The parent homepage remains exhibitor-first from the navigation to the final
  request.
- International editions appear in the first chapter rather than being hidden in a
  secondary directory.
- The page alternates warm editorial chapters with dark event/evidence stages.
- SPIMAR yellow remains an action and orientation color, not a luxury-gold effect.
- Documentary property-exhibition imagery carries the experience.
- Rounded geometry is controlled rather than turning every element into a pill.
- Each chapter uses a different silhouette: film stage, editorial split, timeline,
  metric field, trust wall, case spread, comparison matrix, gallery, toolkit and
  conversion close.
- One global header and one audience-grouped footer frame the full experience.
- Unknown business facts remain visibly pending instead of receiving fictional
  numbers, checkmarks, prices, logos or testimonials.

### 3.2 CTA hierarchy

The complete page uses this hierarchy:

1. `Devenir exposant` — global primary action.
2. `Télécharger la brochure` — global secondary evaluation action.
3. `Demander une proposition` — edition/package-aware qualified action.
4. Contextual actions — case, gallery, resources, FAQ and visitor routes.

Production copy must use one approved verb per action state. `Devenir exposant` must
not mean that a stand is reserved. `Demander une proposition` must not mean that
pricing or availability is confirmed.

### 3.3 Provisional visual rules carried by the assembly

These rules are direction-level and still require deterministic design tokens:

| Area           | Part 10 direction                                                                                    |
| -------------- | ---------------------------------------------------------------------------------------------------- |
| Brand yellow   | `#EFC337` starting point, pending source-brand confirmation                                          |
| Main canvases  | Near black, graphite, warm white and light neutral                                                   |
| Grid           | 12 columns within an approximately 1320–1440 px content canvas                                       |
| Section rhythm | Approximately 88–160 px vertical spacing                                                             |
| Card radii     | Controlled 14–20 px where a bounded surface improves hierarchy                                       |
| Buttons        | Rounded rectangles with clear focus/pressed/disabled states; avoid sharp corners and universal pills |
| Borders        | Hairline neutral borders; yellow only for emphasis or active state                                   |
| Elevation      | Subtle surface separation; no glassmorphism or decorative shadow stacks                              |
| Typography     | Contemporary grotesk/sans hierarchy plus compact technical metadata                                  |
| Media          | Rights-cleared SPIMAR event film and photography for published proof                                 |

### 3.4 Transition review

The following transitions are intentional:

- light hero/event discovery → light objection handling;
- light reasoning → dark operating method;
- dark method → dark measurement proof;
- dark measurement → light MRE market intelligence;
- light visibility system → dark promoter trust;
- dark trust → light case-study evidence;
- light package decision → light documentary gallery introduction and dark media;
- dark media → light resources and FAQ;
- light resources → light qualified request → dark footer.

Before implementation, transitions must be rebuilt as semantic sections rather than
independent 1024 px panels. Section heights respond to real content and viewport
width; they are not fixed to the exploration images.

## 5. Known limitations and open design work

### Image-generated reference limitations

- Small text may contain visual-generation inaccuracies.
- Exact line breaks, spacing, alignment and component dimensions are not source
  specifications.
- Form fields, dropdowns, carousels, video controls, accordions and comparison
  tables are visual states, not tested components.
- The images do not prove keyboard, screen-reader, responsive, loading, error or
  reduced-motion behavior.
- Generated people or scenes cannot be published as real-event evidence.

## 6. Accessibility and implementation review

Part 10 does not waive the existing WCAG 2.2 AA target. The deterministic version
must include:

- semantic heading order and landmark structure;
- visible focus on light and dark surfaces;
- keyboard-operable menus, filters, carousels, video, accordions and forms;
- text equivalents for every icon and status;
- captions and transcripts for published video;
- contrast that does not depend on yellow alone;
- 44 px touch targets where practical;
- reduced-motion support;
- error summary, inline error and recovery states;
- logical FR/EN reading order and independently composed Arabic/RTL order.

## 7. Analytics continuity

The complete page must preserve a single event taxonomy across sections:

- hero exhibitor CTA and brochure start/complete;
- edition impression, selection and exhibitor/visitor route;
- case-study open and testimonial playback;
- proof-definition access;
- package comparison and proposal start/complete;
- gallery filter, media open and playback;
- resource access and FAQ topic;
- qualified-request start, validation error, durable acceptance and CRM delivery;
- locale and audience-route changes.

Form values and other personal data must not enter analytics payloads.
